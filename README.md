# Smart CRM Dashboard

## 🚀 AI-Powered Customer Relationship Management

A comprehensive Smart CRM solution featuring 22 AI agents, video calling, analytics, and whitelabel partner management.

### ✨ Key Features

- **22 AI Agents Ecosystem** - Complete automation suite
- **Video Calling System** - Built-in communication platform
- **Analytics Dashboard** - Real-time reporting and insights
- **WhiteLabel Partner System** - Multi-tenant architecture
- **Contact Management** - Advanced customer relationship tools
- **Deal Pipeline** - Sales process optimization
- **Task Management** - Workflow automation
- **Marketing Tools** - Campaign management and analytics

### 🛠️ Tech Stack

- **Frontend:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Framer Motion
- **State Management:** Zustand
- **Database:** Supabase
- **AI Integration:** OpenAI, Google Gemini, Anthropic Claude
- **Voice:** ElevenLabs
- **Deployment:** Netlify

### 🚀 Quick Start

1. Clone the repository
2. Install dependencies: `npm install`
3. Configure environment variables
4. Run development server: `npm run dev`
5. Build for production: `npm run build`

### 🔧 Environment Variables Required

```bash
VITE_GOOGLE_AI_API_KEY=your_google_ai_key
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_key
VITE_OPENAI_API_KEY=your_openai_key
```
